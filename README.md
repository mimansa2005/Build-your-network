## ⚡ THE MISSION

What if delivering a parcel wasn't just about reaching a destination—but finding the **smartest route, beating the clock, and maximizing efficiency?**

**Build Your Network** turns logistics into a fast-paced interactive challenge where players connect delivery locations, optimize routes, race against time, and compete for the highest score.

Inspired by the real-world decisions behind modern logistics, this game brings the Speedo Express delivery network to life.

**Your mission:** Connect the route. Beat the clock. Maximize your stars. Earn your place on the leaderboard.

---

## 🎮 THREE ROUNDS. ONE CHAMPION.

| Round | Difficulty | Challenge | Maximum Stars |
|:---:|:---:|---|:---:|
| 🚚 01 | Easy | Master the basics | 20 |
| 📦 02 | Medium | Think faster, route smarter | 30 |
| 🏃 03 | Tough | Handle the ultimate delivery challenge | 50 |
| 🏆 | **TOTAL** | **Perfect your entire network** | **100** |

### 🧠 More than just connecting dots

- **Route optimization:** Find the shortest possible route through the delivery network.
- **Time-based gameplay:** Make smart moves while racing against the clock.
- **Progressive difficulty:** Take on increasingly challenging rounds.
- **Star-based scoring:** Earn up to 100 stars across all three rounds.
- **Leaderboard competition:** See how your performance stacks up against other players.
- **Perfect-run objective:** Aim for the ideal route and ideal time in every round.

*Think you've got what it takes to run an efficient delivery network? Prove it.*

## 🎯 WHY THIS PROJECT?

Logistics is a real-time optimization problem.

Behind every delivery are decisions involving routes, time, distance, resources, and efficiency. This project translates that idea into an accessible game that makes people experience the thinking behind a delivery network.

It also demonstrates how an interactive event experience can combine:

- Gamification and user engagement
- Algorithmic thinking and route optimization
- Responsive frontend development
- Cloud database integration
- Real-time competition and score tracking

**The idea is simple: make logistics engaging, one route at a time.**

## 🚀 RUN IT LOCALLY

### Prerequisites

- Node.js
- Bun, if using the included `bun.lock`
- A configured Firebase project

### Installation

```bash
git clone https://github.com/YOUR_USERNAME/build-your-network.git
cd build-your-network
bun install
```

### Start development

```bash
bun run dev
```

### Create a production build

```bash
bun run build
```

Replace `YOUR_USERNAME` with your GitHub username. Check `package.json` for the actual scripts before running these commands.
